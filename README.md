# STM32 OTA Bootloader

基于 STM32 + W25Q 外部 Flash + ESP8266 WiFi 的 OTA 固件升级系统。

## 架构概览
                 服务器 (TCP)
    推送固件 + 元数据 (长度/版本/CRC32)
                   |
              WiFi (ESP8266)
                   |
 +-----------------v-------------------+
 |         OTA 程序 (Download 区)        |
 |                                      |
 |  DMA 循环接收 --> 写入外部 Flash       |
 |  CRC 校验通过后写入 EEPROM 元数据      |
 +-----------------+-------------------+
                   |
 +-----------------v-------------------+
 |          外部 Flash (W25Q)            |
 |   +--------+--------+--------+      |
 |   | 分区 0 | 分区 1 | 分区 2 | ...  |
 |   | 512KB  | 512KB  | 512KB  |      |
 |   +--------+--------+--------+      |
 |        4 分区轮换存储                  |
 +-----------------+-------------------+
                   |
 +-----------------v-------------------+
 |       Bootloader (Bootloader 区)      |
 |                                      |
 |  读 EEPROM -> 校验外部 Flash          |
 |  -> 写入内部 Flash APP 区             |
 |  -> 写入后 CRC 校验 -> 跳转 APP       |
 +-----------------+-------------------+
                   |
 +-----------------v-------------------+
 |          内部 Flash (APP 区)           |
 |            用户应用程序                |
 +--------------------------------------+
